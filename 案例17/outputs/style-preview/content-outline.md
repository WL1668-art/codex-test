# 《把 AI 视频从“抽卡”变成可控创作》内容骨架

| 页码 | 页面标题 | 唯一核心信息 | 页面类型 | 推荐视觉表达 | 模式 |
|---:|---|---|---|---|---|
| 01 | 把 AI 视频从“抽卡”变成可控创作 | 稳定输出来自可解释的创作决策，而非等待一次完美生成 | 封面 | 一个强标题配一处主题视觉；保留大量留白 | Hero |
| 02 | “抽卡感”从哪里来 | 不稳定首先来自输入、评价标准和后期目标都没有显性化 | 问题诊断 | 将一次生成拆成“输入不清、候选不足、选择无标准、衔接未设计”四个失控点 | Object |
| 03 | 提示词的三层结构 | 基础设定、氛围与画质、画面内容分别解决“是什么、像什么、怎么发生” | 方法框架 | 三层纵向结构；每层只保留一个问题和一个例子 | Object |
| 04 | 从剧本到资产画布 | 生成前先把角色、场景、道具和状态变成可核对的资产 | 系统图 | 剧本文字位于左侧，资产分组居中，画布节点在右侧 | Object |
| 05 | 单镜头候选池 | 一次任务应产生可比较的候选，而不是押注一个结果 | 实验设计 | 同一镜头的参数矩阵与候选条带；突出“保留标准” | Object |
| 06 | 多分镜的约束与自由 | 锁定动作阶段、景别和运镜，同时给高速构图留出空间 | 分镜方法 | 横向分镜带；每格标出“必须发生”与“允许变化” | Object |
| 07 | 连续性在后期完成 | 动作方向、镜头运动、光线和色温决定片段能否接在一起 | 对照分析 | 剪辑时间线配前后镜头对照；标出四个连续性检查点 | Object |
| 08 | 一套完整工作流 | 可控创作是一条从意图到素材池、再到剪辑判断的闭环 | 流程总览 | 线性主流程配两次回环：候选不足返回生成，连续性不足返回选片 | Object |
| 09 | 五条行动原则 | 先写评价标准、先核对资产、保留候选池、检查连续性、保留自主判断 | 行动清单 | 五条大字号原则沿同一基线排布，不做卡片墙 | Object |
| 10 | 创作者负责最后一次选择 | 工具负责生成可能性，作者负责取舍、连接和叙事 | 结尾 | 一句结论配单幅画面或纯排版收束 | Hero |
