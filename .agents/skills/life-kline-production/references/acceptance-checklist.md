# 最终验收清单

## 数据

- [ ] validator 返回 PASS，节点数大于 0。
- [ ] 字段完整，年份非递减，重复年份被保留。
- [ ] OHLC/volume 为 0–100，关系与连续性合法。
- [ ] chapter 是宏观章节，phase 是节点走势标签。
- [ ] 页面中的 candles 与锁定数据逐项一致。

## 状态机与节奏

- [ ] 五状态均可到达：opening、travel、focus、chapterReview、globalReview。
- [ ] opening 不自动跳过；桌面空格和按钮都能开始。
- [ ] 每章结束停在 chapterReview，用户继续后才进入下一章。
- [ ] 轨迹连续前进，K 线延迟约 220ms，volume 再延迟约 140ms。
- [ ] 暂停冻结轨迹、节点、volume、镜头和计时；恢复不重播或跳帧。
- [ ] 手动上一节点、下一节点、时间轴跳转和重新开始有效。
- [ ] 最终进入目标节点总数的 globalReview。

## Canvas 与镜头

- [ ] 所有 K 线、上下影线、轨迹和 volume 均由锁定数据映射。
- [ ] travel/focus 连续跟拍且不抖动；focus 轻微靠近。
- [ ] chapterReview 能看清本章完整走势。
- [ ] globalReview 能看到全部节点且不再自动移动。
- [ ] 当前年份与约年龄正确，高亮克制且不被裁切。
- [ ] 首末节点、标签和高亮具有安全边距。

## 四主题

- [ ] 暮山紫、宫墙朱、山水墨、暗夜盘在全部五状态可读。
- [ ] Canvas 随主题重绘，DOM 弹层、时间轴和按钮同步换色。
- [ ] 切换主题不改变状态、进度、镜头或计时。
- [ ] 暗夜快速切换可返回此前亮色主题。

## 手机与窄屏

- [ ] 375、390、430、768px 无整页横向溢出。
- [ ] 手机只靠触摸可走完整流程；提示使用“轻点开始/继续”。
- [ ] 主要按钮不裁字，触控区域约 44px 或更大。
- [ ] 时间轴可手指横向滚动且自动跟随当前节点。
- [ ] chapter 导航随当前章滚入可视区域。
- [ ] globalReview 年份自适应抽稀且不碰撞；K 线、轨迹、volume 不删减。
- [ ] 末节点年份、年龄标签和当前高亮完整可见。

## Reduced motion

- [ ] reduced-motion 下 opening 与每次 chapterReview 仍等待用户。
- [ ] 减少的是过渡、插值或局部揭示动画，而不是交互步骤。
- [ ] reduced-motion 完整流程仍进入 globalReview。

## 浏览器与回归

- [ ] 浏览器控制台无 JavaScript 错误。
- [ ] 主题切换、resize、暂停恢复和连续完整播放无异常。
- [ ] 桌面视觉和既有控制无回归。
- [ ] 至少检查一个反例或失败路径并记录结果。

## Git 前检查

- [ ] 再运行 validator、最相关浏览器验收和 `git diff --check`。
- [ ] `git status --short` 中只有本任务预期文件进入暂存区。
- [ ] 不提交截图、缓存、浏览器 profile、临时服务脚本或无关目录。
- [ ] 不修改 Git 全局配置，不直接提交到受保护默认分支。
- [ ] push、PR、发布或 merge 仅在获得相应授权后执行。
