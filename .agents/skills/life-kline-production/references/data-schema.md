# Candles 数据规范

## 结构

每个节点是一个对象，字段固定为：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `year` | 整数 | 节点发生年份；按数组顺序非递减，允许同年多节点。 |
| `age` | 非负数字 | 节点时约年龄；可为整数或小数，不要求伪精确。 |
| `title` | 非空字符串 | 简短、可扫读的事件标题。 |
| `open` | 0–100 数字 | 阶段起点处境。 |
| `high` | 0–100 数字 | 阶段触及的机会、权力或影响力上限。 |
| `low` | 0–100 数字 | 阶段承受的风险或代价下限。 |
| `close` | 0–100 数字 | 阶段结束处境。 |
| `volume` | 0–100 数字 | 事件改变人生走势的强度。 |
| `chapter` | 非空字符串 | 多节点共享的宏观叙事章节。 |
| `phase` | 非空字符串 | 当前节点自己的短走势标签。 |
| `note` | 非空字符串 | 一句话说明事件及其走势意义。 |

## 数值与连续性

- 每个 OHLC 与 volume 必须位于 `0–100`。
- 每条满足 `low <= open <= high` 且 `low <= close <= high`。
- 默认要求下一条 `open` 等于上一条 `close`，形成连续走势。
- 同一年可拆为多条独立节点；不得仅因年份相同而合并或去重。
- 数值是叙事指数。文案不得暗示其为可复现实证测量或史学共识。

## Chapter 与 Phase

- `chapter` 是宏观分组：数量少、持续多个节点、用于章节导航与 chapterReview。
- `phase` 是节点走势标签：简短、针对本事件，例如“低位求生”“战局突破”“高位震荡”。
- `phase` 不应机械重复 chapter 名称。
- 项目声明章节白名单时，每个 chapter 必须属于白名单；未声明时至少要求非空并检查章节顺序合理。

## 数据锁定

数据锁定前可以修正事实、拆并节点、调整章节和数值。锁定条件：

1. 研究范围和争议表述已确认；
2. 字段完整且 validator 为 PASS；
3. 节点数量、顺序、章节和整体曲线得到用户确认；
4. 页面尚未开始，或页面只存在不含人物数据的通用骨架。

锁定后，页面制作只能消费数据。发现确需改数据时，暂停实现，说明原因，回到数据阶段重新确认并再次验证；不得为了动画或布局方便静默改数值。
